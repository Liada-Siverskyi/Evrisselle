# Licensing and branding

Ionis Undecima uses KDE source and packaging from openSUSE. The project must keep the license and copyright notices attached to each upstream component and preserve the source offer for every distributed GPL binary.

For every update:

- retain upstream `LICENSES/`, copyright notices, and source attribution;
- publish the exact source archive, downstream patch set, spec, and build instructions used for the RPMs;
- keep the license expressions from the individual RPM packages instead of assigning one license to the whole Plasma stack;
- mark Evrisselle changes clearly in patches and release notes;
- review any new dependency or copied file under its own license before including it.

KDE and Plasma names may be used to identify the upstream software accurately. Evrisselle branding must remain distinct, use no KDE logo, and avoid language that suggests KDE publishes or endorses Ionis Undecima. The first session entry uses product branding and describes its technical relationship to Plasma.

This repository does not yet declare a blanket license for original Evrisselle code. Before adding original source code or publishing an MVP, choose and document a license for those files separately from the licenses of upstream KDE components.
